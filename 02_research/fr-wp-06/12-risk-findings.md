# FR-WP-06 — Risk Findings

| Risk | Financial-model finding | Control |
|---|---|---|
| RISK-002 Trade/services/hybrid confusion | lane economics can be compared but must never be blended operationally | separate P&L, contracts, marketing and governance |
| RISK-003 Unsustainable trade-title economics | thin wholesale contribution and returns can drive extreme break-even | channel/title P&L + stress testing before acquisition |
| RISK-004 Defective rights/royalty terms | economics depend on contract-defined basis/rate | counsel + configurable model; no term approval |
| RISK-005 Incorrect royalty accounting | timing/basis can diverge across channels | dedicated accrual/reconciliation/audit controls later |
| RISK-006 ISBN provenance errors | migration/re-edition may create avoidable cost/control problems | registry/provenance work before implementation |
| RISK-007 Distributor/returns exposure | return chargebacks can erase margin | return sensitivities and reserve model |
| RISK-008 Service underpricing | labor/revision/support overrun can eliminate margin | bottom-up cost floor and scope controls |
| RISK-009 Misleading service marketing | economic pressure can incentivize overpromising | no sales/outcome guarantees; separate Lane C governance |
| RISK-010 Cash-flow strain | profitable titles can still consume cash before receipts | cash-conversion model + reserves |
| RISK-011 Premature acquisition | break-even output is not acquisition authority | Human Owner gate preserved |
| RISK-015 Vendor/platform dependency | economics can change abruptly | live rechecks and multi-channel portability |
| RISK-016 Conflicting documentation | stale assumptions could be mistaken for approved facts | source register, dates, lifecycle labeling |

No risk is closed, downgraded, or accepted by FIN-01.
